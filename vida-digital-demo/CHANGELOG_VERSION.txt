MEMORICORDE — VERSIÓN MÉTRICAS CONSOLIDADAS — 2026-10-04

Versión de partida:
- Memoricorde — Última versión correcta — 2026-10-02
- Archivo de referencia: Memoricorde-ultima-version-correcta-2026-10-02.zip

Objetivo de esta versión:
- Consolidar las métricas de consumo de IA tomando la tabla uso_ia como fuente
  principal del consumo real registrado por llamada.

Cambios realizados:
1. main.py
   - /api/metricas utiliza uso_ia para calcular tokens y coste de las sesiones
     cuando existen registros reales asociados a la sesión.
   - Una sesión puede acumular correctamente varias llamadas (entrevista y
     cierre_sesion) sin recalcular el coste desde datos históricos acumulados.
   - El coste de autobiografía se obtiene de todas las operaciones registradas
     en uso_ia: índice, capítulos, mejoras y autobiografía completa.
   - El coste de reconstrucciones se obtiene de sus llamadas reales registradas
     en uso_ia y se mantiene el desglose por reconstrucción.
   - El coste de aportaciones externas se incluye en el coste total.
   - Los tokens totales incluyen sesiones, autobiografía, reconstrucciones y
     aportaciones externas, evitando la omisión existente en la versión anterior.
   - Se mantiene un mecanismo de compatibilidad para datos históricos que no
     dispongan todavía de registros en uso_ia: sesiones y autobiografía pueden
     utilizar sus tokens almacenados como respaldo.
   - No se modifican las funciones que realizan las llamadas a Anthropic ni el
     registro de uso_ia.

2. static/app.html
   - Se mantiene la vista existente de Métricas de uso.
   - Se añade un desglose visible de consumo por operación, con número de
     llamadas, tokens y coste.
   - No se modifica el editor visual de Recuerdos ni las demás vistas.

Archivos afectados:
- main.py
- static/app.html
- CHANGELOG_VERSION.txt

Comprobaciones realizadas:
- Tabla uso_ia y registrar_consumo_ia revisados.
- Rutas de registro de consumo de entrevista, cierre de sesión, aportación
  externa, reconstrucción y operaciones de autobiografía revisadas.
- main.py supera comprobación de sintaxis con py_compile.
- JavaScript de app.html supera comprobación de sintaxis con Node.
- Diff respecto a la versión de referencia: únicamente main.py y app.html
  contienen cambios funcionales.
- No se incluye ninguna base de datos de producción.

Limitación de verificación:
- No se pudo ejecutar una prueba integrada completa de FastAPI y SQLCipher en
  este entorno porque falta el paquete Python bcrypt. Por ello no se afirma
  que el endpoint haya sido ejecutado extremo a extremo aquí.
